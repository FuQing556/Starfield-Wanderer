# 业务逻辑复查报告（设计意图 vs 代码实际）

> 复查日期：2026-08-11 傍晚
> 起因：用户发现光查代码问题不够，要对照"设计意图"复查"代码实际在干嘛"
> 结论：4 个核心发现，其中 3 个已修复，1 个待清理

---

## 🔴 核心发现 1：世界怪"近战"是假功能（已定案）

**实际流程：** 敌人视野发现玩家 → 读条 3 秒 → 读满 → `inBattle = true` → `BattleManager.OnBattleStart` → **玩家被传送进竞技场**，世界怪原地冻结（`EnemyBase.cs` 的 `shouldFreeze = vision.InBattle`）。

**结论：** 世界怪的近战/前摇/冷却/攻击距离/背刺全部永远不会执行——从 P3.5 引入竞技场那天起就被架空了。

**设计决策（用户拍板，选 B）：** 维持竞技场。**世界怪 = 无敌战斗触发器，竞技场 = 真正的战斗。**

---

## 🔴 核心发现 2：野外触发器会被磨死（真 bug，已修复 ✅）

**问题：** 世界怪吃玩家近战伤害。玩家打输竞技场出来再砍它、再输、再砍——血一点点磨，连输几次触发器就被磨死在野外。

**修复：** `EnemyBase.TakeDamage` 中，带 VisionComponent 的（= 野外触发器）首击处理后直接 return **不扣血**，但仍跑 `ProcessFirstStrike` 判定背刺/正面。竞技场怪（无视野）不受影响。

---

## 🔴 核心发现 3：背刺"半血"设计没接上（已修复 ✅）

**用户设计：** 背刺 → 进入战斗后，所有竞技场怪初始半血。

**代码实际（修复前）：** 背刺只把"世界触发器自己"设成半血——触发器无敌且会被销毁，这半血毫无意义。

**修复：**
- `VisionComponent` 背刺时调用 `OnBattleStart(gameObject, 0, isBackstab: true)`
- `BattleManager` 存 `backstabBattle` 标记，`SpawnWave` 出怪时对所有竞技场怪 `SetHealth(半血)`

**现在的进战斗梯度：**

| 进战斗方式 | 竞技场怪 | 同伴 |
|-----------|---------|------|
| 背刺（背后偷袭） | 半血 | 无 |
| 正面砍 | 满血 | 无 |
| 被发现（读条满） | 满血 | 呼唤同伴 ×N |

## 🟠 核心发现 4：磁铁护符是空技能（待清理 ⏳）

**问题：** `MagnetCharm` 只有枚举定义 + 技能栏图标（`SkillBarUI`），**没有任何"自动吸取掉落物"的代码**。广告了但没货。

**用户确认：** 废弃设计——早期四件套饰品被"源珠"替代。删残留（枚举 + 图标），不实现。

**注意：** 闪现衣 `BlinkDodge` **保留**——它就是源珠的技能（空格闪现 + 双发），PlayerAttack 有完整实现，正常工作。被删的是"闪现衣"装备本身，技能被源珠继承了。
