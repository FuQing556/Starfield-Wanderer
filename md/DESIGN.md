# 星野旅人 (Starfield Wanderer) — 游戏设计文档 v3.0

> 最后更新：2026-08-11 07:00
>
> **核心原则：钥匙永远不在锁旁边。**
> 装备不是数值填槽，是改变世界规则的钥匙。
> 先设计玩家感受，后设计装备功能。

---

## 1. 设计哲学

做游戏不是搭积木。不是"有四个槽位所以塞四件装备"。

正确顺序：
1. 先定环境规则 → 玩家进入这个区域会有什么感受？
2. 再定解锁钥匙 → 什么东西能打破这个规则？
3. 钥匙放在前一个区域 → 形成"被虐 → 拿钥匙 → 回来碾压"的体验弧
4. 最后定数值 → 平衡性的东西，最后调

**游玩路线固定：西山 → 南林 → 东海 → 北荒。** 不是开放世界选方向，是难度递进的线性路径（只是地图上看起来像四个方向）。

---

## 3. 四个区域（从玩家感受出发）

### 西·荆棘山丘（★ 最简单）

**环境规则：** 地面到处是荆棘，踩上去持续扣血。只有碎石小路是安全的。
**玩家感受：** "走两步就掉血，只能沿着窄路走，怪还挡在路上。"
**入口钥匙：防刺靴** — 商人处用金币买。穿上后免疫荆棘伤害。
**地牢 Boss：荆棘女王**
**传说奖励：明灯** — 照亮大范围迷雾。

> 明灯不在这里用。西山的雾不浓，不需要灯。
> 明灯是给南林的。

---

### 南·幽暗密林（★★）

**环境规则：** 浓雾笼罩，视野只有身边一小圈。敌人从雾里冲出来。
**玩家感受：** "什么都看不见，听到怪的声音但不知道在哪。"
**入口钥匙：明灯** — 西山奖励。装备后驱散雾。
**地牢 Boss：迷雾之主**
**传说奖励：避水珠** — 免疫海流 + 无限水下呼吸。

> 避水珠不在海里。南林没有水。

---

### 东·潮汐海岸（★★★）

**环境规则：** 海流把人往深处推，必须定期上岸换气（氧气条）。水下洞穴有隐藏内容。
**玩家感受：** "站不住，被推来推去，打怪时还要算氧气。"
**入口钥匙：避水珠** — 南林奖励。装备后免疫海流 + 无限呼吸。
**地牢 Boss：深渊巨兽**
**传说奖励：暖玉** — 免疫寒冷 + 常速移动。

> 暖玉不在冰原。东海是温暖的。

---

### 北·冰霜废土（★★★★ 最难）

**环境规则：** 刺骨寒冷持续减速。地图上散落火堆，靠近才恢复正常速度。火堆之间是死亡地带。
**玩家感受：** "每一步都慢如蜗牛，必须在火堆之间规划路线，离开火就绝望。"
**入口钥匙：暖玉** — 东海奖励。装备后寒冷无效。
**地牢 Boss：冰霜巨龙**
**传说奖励：星辰之核** — 最终装备，集齐四件的证明。不在游戏流程中使用，是通关标记。

## 4. 完整玩家旅程

```
开局（营地）
  │  商人：买防刺靴（花初始金币）
  │  提示："西边的山丘有东西在等你"
  ▼
西山·荆棘山丘（带防刺靴 → 无视荆棘）
  │  采集 + 打怪 + 地牢
  │  Boss：荆棘女王
  │  获得：明灯
  │
  ▼
南林·幽暗密林（带明灯 → 驱散迷雾）
  │  采集 + 打怪 + 地牢
  │  Boss：迷雾之主
  │  获得：避水珠
  │
  ▼
东海·潮汐海岸（带避水珠 → 无视海流+无限呼吸）
  │  采集 + 打怪 + 水下地牢
  │  Boss：深渊巨兽
  │  获得：暖玉
  │
  ▼
北荒·冰霜废土（带暖玉 → 无视寒冷）
  │  采集 + 打怪 + 地牢
  │  Boss：冰霜巨龙
  │  获得：星辰之核
  │
  ▼
通关！
```

每个区域需要上一区域的奖励才能正常探索。如果玩家想跳过西山直接去南林，浓雾会让游戏几乎无法进行——不是硬锁，是**软锁**（理论上能摸索过去但极痛苦）。

## 5. 需要新增的系统

| # | 系统 | 说明 | 优先级 |
|---|------|------|--------|
| 1 | **环境规则系统** | 荆棘扣血、迷雾遮蔽、海流推力、寒冷减速 | 🔴 核心 |
| 2 | **区域解锁逻辑** | 检测玩家是否持有对应钥匙装备 | 🔴 核心 |
| 3 | **氧气条** | 东海专用，入水倒计时，上岸重置 | 🟡 东海 |
| 4 | **Boss 敌人** | 4 个 Boss，比普通 ArenaEnemy 复杂 | 🟡 |
| 5 | **商人初始物品** | 防刺靴 + 基础血瓶，用初始金币购买 | 🟢 |
| 6 | **简单引导** | 对话/文字指引玩家去下一个区域 | 🟢 |
| 7 | **通关判定** | 四件传说装备集齐 → 胜利 | 🟢 |

---

## 6. 重构需求（由新系统推动）

| 重构项 | 为什么必须做 |
|--------|-------------|
| Enemy 统一基类 | Boss 可能同时出现在世界和竞技场 |
| GameManager 全局状态 | 追踪已获得的传说装备、已通关的地牢 |
| 环境规则系统 | 新模块，需要挂在每个区域的父物体上或做区域检测 |

---

## 7. 不做的事

- ❌ 随机地图（固定地图，手摆采集物和敌人位置）
- ❌ 存档系统（后期再加）
- ❌ 角色动画（用 flipX 翻转朝向）
- ❌ 音效（P6 统一加）
- ❌ 手机适配（先 PC）
