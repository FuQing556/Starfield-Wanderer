# 星野旅人：世界、素材与后续开发总规划

> 最新更新：2026-08-13
>
> **本文件是当前唯一有效的世界设定与后续开发规划。** 本次讨论确定的内容覆盖旧版 `DESIGN.md`、旧素材候选和早期区域设想；以后接手项目先读本文件，再看代码与学习日志，不要根据旧文档自行恢复虫怪优先、蓝火怪首 Boss、四区旧机制等方案。
>
> 实施原则：规划可以完整记录，但开发仍然一次只做一个小闭环；先讲清数据流和测试结果，再写下一步代码。

---

## 1. 当前已完成与最近状态

### 主角表现

- 正式主角：Sscary Female Adventurer。
- 已完成六方向 Idle / Walk / Dash / Death、普通影子、闪现扬尘、倒地影子与死亡停顿。
- 世界地图普攻已正式改为近距离法术“星尘冲击”，不再理解为挥剑。
- 星尘冲击为独立 VFX 实例：生成后脱离 Player，在世界坐标中移动、播放并自行销毁。
- 世界地图伤害判定：以攻击起点为圆形粗筛，再取前方 `100°`、半径 `1.5` 的扇形目标；伤害可延迟结算。
- 电脑端世界普攻与竞技场射击都由鼠标决定方向。
- 手机端必须保留两套有意不同的方向规则：
  - 世界地图近距离法术：摇杆**正方向**；无摇杆输入时使用最后移动方向。
  - 竞技场远程射击：摇杆**反方向**；这是为了允许玩家边远离敌人边回头射击，不得擅自统一。
- 主角六方向动画仍按移动方向播放，不需要为了鼠标攻击方向再做一套施法朝向。

### 战斗表现分级

| 层级 | 视觉方向 | 用途 |
|---|---|---|
| 普通攻击 | 蓝白 / 淡青、高对比但克制 | 星尘冲击、基础弹道、命中火花 |
| 装备技能 | 更复杂、更明亮的像素 VFX | 散射、穿透、闪现强化、稀有能力 |
| 精英 / Boss | 大范围预警、独特颜色与节奏 | 剑气、召唤、冲锋、区域机制 |

### 眼下尚未完成

- 新怪物素材尚未形成可复用的动画接入管线。
- 出生营地仍需正式地图美术与黄色主力怪生态。
- 怪物波次组合、受击动画、死亡动画和不同敌人定位尚待接入。
- 背包物品、HUD 五颗心方案、远程攻击特效和怪物攻击特效仍待打磨。

## 2. 世界总结构

世界由“中土快乐老家 + 东西南北四个独立区域”构成：

```text
                         北荒
                 冰雪 / 风偏 / 血怪
                           │
                           │ 北门
                           │
        西山 ── 西门 ── 中土营地 ── 东门 ── 东海群岛
    火域 / 裂缝 / 恶魔       │               外交 / 入侵
                           │ 南门
                           │
                         南林
                   紫雾 / 陷阱 / 女巫
```

### 技术结构

- 现阶段仍使用同一个 `MainWorld` 场景。
- 中土、西山、南林、北荒和东海做成彼此隔开的 Tilemap 地图块，不要求在空间上真实相连。
- 中土四方门负责传送到四区入口；东海各岛使用渡船、传送点或短黑屏移动。
- 继续沿用同场景传送，暂不引入多场景存档和跨场景数据传递复杂度。
- 每个区域需要独立的入口点、返回点、复活点与相机瞬移处理。

### 五区颜色与定位

| 区域 | 主色 / 主力变体 | 核心体验 | 环境压力 | 玩家主要依赖 |
|---|---|---|---|---|
| 中土 | 黄色哥布林、黄色人类 | 安逸家园、教学、区域预告 | 低 | 基础操作与成长反馈 |
| 西山 | 红色哥布林、红色人类 | 地狱山路、危险位移 | 裂缝、狭路、坠落 | 高机动性与位移装备 |
| 南林 | 紫色哥布林、紫色人类 | 迷雾探索、伏击与陷阱 | 低视野、错误路线、地面陷阱 | 观察、照明、探测与解毒 |
| 东海 | 蓝色哥布林、蓝色人类 | 群岛外交、入侵与阵营选择 | 岛屿隔离、潮汐/浅水、关系变化 | 交易、外交选择与阵营支援 |
| 北荒 | 五类血怪为主，少量蓝色外来者 | 冰封血原、资源消耗、近距离压迫 | 风雪、子弹偏移、低视野 | 药水、复活道具、接近战斗 |

“火、木、水、冰”是区域环境和玩法的构建方向，不要求当地所有怪物都使用元素攻击。

## 3. 地图规模与通用画法

### 第一版建议规模

以当前游戏实际镜头可见范围作为“一屏”，不要先按 Tile 数追求巨大地图：

| 区域 | 第一版规模 | 形状 |
|---|---:|---|
| 中土 | 约 `3×3 屏` | 中央营地向四门放射 |
| 西山 | 约 `3×5 屏` | 纵向攀登、多层山路 |
| 南林 | 约 `4×4 屏` | 多个雾中房间相连 |
| 北荒 | 约 `5×3 屏` | 横向穿越的开阔风场 |
| 东海 | 4～5 座岛，每岛约 `1～2 屏` | 渡船连接的离散小地图 |

规模不是硬指标。每区第一版只要具备以下结构，就已经足够完整：

- 5～7 个能被玩家记住的地标；
- 1 条清晰主路线；
- 1 条高风险支路；
- 1 条获得区域能力后才能使用的捷径；
- 1 个安全点 / 复活点；
- 1 个精英区域；
- 1 个 Boss、地牢入口或区域终点。

### 素材少时的最小地图素材包

每个区域先凑齐以下内容即可开画：

- 2 种基础地面；
- 1 种道路或地面过渡；
- 1 种边界素材（树墙、悬崖、水岸、冰墙等）；
- 1 种区域危险物；
- 3～5 种可重复装饰；
- 1 个大型地标；
- 1 层天气、雾、雪、火星或水面粒子。

区域辨识度主要由**地图轮廓、路线、主色、天气和机制**建立，不依赖几十种地砖。装饰物需要错落、旋转、镜像或形成簇，避免均匀撒点。

### 通用地图节奏

```text
安全入口 → 第一次展示环境规则 → 普通战斗
        → 安全点 / 地标 → 规则与敌人组合
        → 危险支路 / 精英 → 捷径回开头
        → 区域终点 / Boss / 地牢
```

环境机制必须先单独教学，再与敌人组合；不要让玩家第一次看到裂缝、风偏或陷阱时同时处理复杂精英。

## 4. 中土：黄色营地与快乐老家

### 地图结构

- 中央是出生营地，四条短道路分别通向东西南北四座门。
- 营地承担商店、箱子、复活、装备整理和世界进度展示。
- 中土总体低压，以草地、土路、树林边界和少量采集点为主。
- 四门周围逐渐出现对应区域的视觉预告，例如裂缝石、紫雾植物、潮湿遗物、冰雪与血迹。

### 怪物与生态

- 黄色哥布林和黄色人类小兵是中土主力。
- 两种哥布林、三种人类小兵来自同一素材包，每类拥有蓝、紫、红、黄四种颜色；黄色版本优先用于第一批完整接入。
- 哥布林偏数量和扰乱，人类小兵偏稳定输出、守路和小队配合；具体怪物层级由符青决定，规划不强行覆盖。
- 四方门附近可以混入对应区域的小怪、弱化精英或超级削弱的 Boss 形态，让玩家提前见到未来威胁。
- 这些早期版本不要直接包装成“同一 Boss 只降数值”，应使用幼体、投影、分身、负伤、残缺、被封印等解释，并减少技能或改变体型。玩家以后遇到完整形态时，应产生“当初那个居然只是残缺版”的冲击。

### 家园成长

- 每完成一个区域，中土就产生可见变化：新增 NPC、商品、战利品、纪念物、难民或商队。
- 女巫商人的商品随区域进度扩充。
- 四方势力可以在门口或营地留下代表角色，为东海外交埋线。
- 中土的价值不是难，而是让玩家每次远征后有“回家”的安全感和成长反馈。

## 5. 西山：火域、地狱风与危险山路

### 当前素材分配

- 少量红色人类与红色哥布林；
- 两个高级恶魔；
- 牛头人；
- 只有 Walk / Run 的剑鬼；
- 镰刀怪；
- 斗篷恶魔。

### 地图与机制

- 西山第一版做成纵向上升地图：山脚、窄坡、裂缝群、废弃营地、恶魔区 / 地牢。
- 核心不是单纯火焰伤害，而是“路不好走”：狭窄通道、断层、裂缝和需要位移跨越的捷径。
- 普通路线必须始终存在，但更绕、更危险；拥有高机动性装备后可以跨裂缝、抄近路或拿支路奖励。
- 掉入裂缝时扣血并回到最近安全落点，不让玩家重复跑完整张地图。
- 火星、红雾、地裂、余烬、枯木、骨骸和火盆负责地狱氛围；不要求每只敌人都喷火。

### 敌人与地形组合

- 红色哥布林、人类：山脚和外围基础敌人。
- 镰刀怪：快速压近，适合守窄路或捷径。
- 斗篷恶魔：远程法术、召唤或逼迫走位。
- 牛头人：重型冲锋，将玩家逼向裂缝，是最适合体现地图机制的怪。
- 剑鬼：游荡精英；因只有站立、走跑动作，攻击表现由蓄力预警、消失、位移与剑气 VFX 承担。
- 两个高级恶魔可分别承担中段强敌与区域 / 地牢 Boss，最终身份以后按动画完整度和视觉体型确认。

### 当前设定覆盖

- 旧版“荆棘山丘 + 防刺靴”为主机制的方案不再是西山当前主线。
- 西山现阶段以“火域地狱风 + 裂缝 + 高机动性装备”作为核心。

## 6. 南林：紫雾、陷阱与女巫真身

### 当前素材分配

- 少量紫色人类与紫色哥布林；
- 两种动作细节丰富的史莱姆；
- 一个蘑菇怪；
- 只有 Walk / Run / Idle / Jump 的猫；
- 只有 Walk / Run / Jump 的女巫。

### 地图与机制

- 南林做成多个相连的“雾中房间”，不是整齐方格迷宫。
- 玩家默认只能看到周围一小圈；远处地形、怪物和岔路被紫雾遮挡。
- 发光植物、火把、女巫路标或临时营地形成安全视野点。
- 陷阱可以坑人，但必须有可学习的视觉线索：压痕、断枝、异常蘑菇、颜色变化、飘动孢子等，不能纯粹不可见。
- 区域能力或装备可扩大视野、显示部分陷阱、净化迷雾或标记安全路线。
- 迷雾应制造信息不足和伏击，不要频繁随机传送玩家或让路线毫无规律。

### 敌人与地形组合

- 两种精细史莱姆是核心生态怪，可分别承担黏液留场、跳扑、分裂等不同机制。
- 蘑菇怪负责孢子、毒雾或改变安全路径。
- 紫色人类、哥布林是进入森林的外来采集者、猎人或被迷雾影响的小队。
- 猫适合稀有高速角色或精英，用 Jump 表现扑击，消失烟雾 / VFX 补足攻击和死亡表现。
- 女巫以法术、传送、迷雾和 VFX 承担战斗表现，不依赖素材自带攻击动作。

### 女巫贯穿世界的设定

- 全世界各地的主要交易商人统一使用女巫模板。
- 当前推荐解释：玩家沿途见到的是同一位女巫投出的分身、雾像或契约代理，因此外形一致且能共享商品体系。
- 女巫在南林最后成为 Boss / 契约战对象，揭示真身与各地分身的关系。
- 推荐战斗结果不是永久杀死她：打赢后完成契约、改变合作关系并解锁高级商品，各地商店继续存在。
- 她同时承担世界串联、区域情报和东海外交的中介角色。

## 7. 北荒：冰封血原、风偏与资源消耗

### 当前素材分配

- 五种造型猎奇的血怪构成主要生态；具体层级由符青按素材动作和体型安排。
- 少量蓝色人类与蓝色哥布林作为外来远征队、拾荒者、失踪者或幸存者。
- 一个独立人类剑士可作为游荡精英、重要人物或被感染者。

### 地图与机制

- 北荒不是普通“全是冰怪”的雪地，而是白雪、冷蓝风暴与鲜红血肉形成强烈反差的冰封血原。
- 地图横向展开：边境哨站、开阔风场、废弃车队、冰洞避风区、血怪巢穴。
- 开阔区域的风会让远程子弹发生可预测偏移；风向必须通过雪粒、旗帜、地面飘雪等明显表现。
- 冰墙、残骸和洞穴后方可以形成避风区，鼓励玩家借地形接近。
- 暴风雪降低视野，血怪负责近距离压迫和资源消耗。
- 药水和复活道具在这里明显更重要；可设置深入荒原后的补给抉择与有限安全点。

### “强制肉搏”的边界

- 当前竞技场主要攻击方式仍是远程子弹，因此不能简单让子弹失效。
- 第一版应做成“越远偏移越明显、靠近后偏移减弱”，逼迫玩家接近但保留选择。
- 若以后竞技场也增加近距离星尘或其他近战能力，再进一步强化北荒的近战收益。
- 风偏必须稳定、可观察、可学习，不能每发随机乱飞。

## 8. 东海：群岛、外交与各地入侵者

### 核心方向

- 不制作无边大海，也暂不制作自由航海系统。
- 东海定义为“小岛群 / 潮汐遗迹”，玩家主要在岛上活动，水面是岛屿之间的空间与边界。
- 通过渡船、固定航线或传送点在岛之间移动。
- 东海素材不足不再视为缺陷：这里本来就是各区域势力、怪物和旅行者交汇的世界交通中心。

### 建议岛屿结构

第一版规划 4～5 座岛，每座只需 1～2 屏：

1. **港口岛**：女巫商店、旅人、任务集散与安全点。
2. **红岩岛**：西山入侵者，可放镰刀恶魔等敌人。
3. **雾岛**：南林势力、女巫事件、史莱姆或蘑菇生态。
4. **冰流岛**：北荒血怪或幸存者随浮冰 / 船只漂来。
5. **遗迹岛**：外交主线、两位其他主角模板与最终立场选择。

岛屿数量可根据素材缩减，重点是每座岛代表一个清晰问题，不铺大量空海面。

### 角色与外交

- 两个其他主角模板放在东海，让玩家第一次遇见“和自己一样的冒险者”。
- 两人可以代表不同立场，例如武力清除与谈判共存，但具体性格待看到素材后确定。
- 女巫继续作为交易与情报中介，将南林个人线和东海阵营线连接起来。
- 来自西山、南林、北荒的怪物可以作为入侵者、雇佣兵、难民护卫、走私者或失控生物出现。

### 外交系统控制范围

第一版不要建立庞大的动态政治模拟。先只做少量明确选择：

- 帮谁清理 / 占领某座岛；
- 把关键物资交给谁；
- 允许哪个阵营建立据点；
- 战斗前选择谈判、交易、威胁或开战。

选择暂时只影响三类结果：

- 哪些角色或怪物会主动攻击玩家；
- 哪个商店、航线或服务开放；
- 区域终局时谁提供支援。

东海的重点是“世界被串起来”，不是靠大量独占怪物堆内容。

## 9. 怪物素材使用总则

### 已有主力素材

- 同一素材包：两种哥布林、三种人类小兵；每类均有蓝、紫、红、黄四种颜色。
- 黄色主供中土，红色主供西山，紫色主供南林，蓝色主供东海。
- 北荒的主力是五类血怪，蓝色人类与哥布林只少量出现，用于说明外来者与世界联系。
- 西山拥有恶魔、牛头人、剑鬼、镰刀怪、斗篷恶魔等高阶素材。
- 南林拥有精细史莱姆、蘑菇、猫、女巫等特色素材。
- 东海允许复用三方敌人，因为“各地势力汇聚 / 入侵”就是其内容设定。

### 动作不完整素材的处理

- 只有 Idle / Walk / Run 的角色，不应强行要求素材自身承担全部战斗表现。
- 可以通过蓄力圈、地面预警、位移、闪现、子弹、剑气、烟雾、命中停顿和死亡消散补足。
- 动作少不等于只能做经验怪；只要 VFX 与机制匹配，也可以做精英、Boss、商人或重要 NPC。
- 但普通怪动画管线仍应优先用至少具有 Idle / Walk / Attack / Hit / Death 的素材跑通，减少首个样板的额外变量。

### 怪物层级

- 各素材究竟属于普通怪、机制怪、精英还是 Boss，符青已有自己的判断，后续以实际素材预览与符青决定为准。
- 本规划只确定区域归属、世界关系和环境组合，不擅自锁死具体层级。

## 10. 采集物、地图物件与 UI 后续

### 资源节点与景观物件必须分开

- `资源树 / 资源矿`：由 `WorldSpawner` 生成，可以受击、改变形态并掉落物资。
- `景观树 / 景观石`：手动摆放的固定环境装饰，可以保留小型树干碰撞和 Y 排序，但不能受击、不会掉落，也不由 `WorldSpawner` 生成。
- 两类物件使用不同 Prefab，不再用静态景观树替换现有资源树 Prefab。

### 资源生成区块与树种分布

- 当前 `TreeSpawner` 使用覆盖大地图的单个矩形，只用于验证资源树数量、碰撞、掉落与性能，不是最终地图结构。
- 后续加入人类据点、哥布林营地、四方门、道路和大型地标后，将树木生成拆成多个独立小矩形区块；区块边界主动绕开建筑、道路和剧情空间，形成明确的禁刷区域。
- 第一版不急着开发多边形禁刷、NavMesh 采样或复杂权重系统。用多个 `WorldSpawner` 组合即可在 Inspector 中直观看到范围、调整数量，也更适合当前地图手工迭代。
- 北方区域以松树为主、白桦为辅；南方区域以白桦为主、松树为辅。中土可以混合两种树，但营地和四条主路附近保持稀疏。
- 树种比例先通过各生成区块的 `Count` 表达，例如同一片北方林地使用较多松树生成器和较少白桦生成器；等地图结构稳定后，再评估是否值得合并为带权重的统一生成器。
- 当前不实现资源重生。地图面积与一次性生成量远高于预期制作需求，先保证采集链和地图布局，不增加没有玩家价值的刷新复杂度。

### 可攻击资源的三阶段表现

基础可攻击资源暂定六种：两种树、两种普通石头、两种金矿。全部使用统一三阶段流程：

```text
满血：大树 / 大石头 / 大型金矿
半血：小树 / 小石头 / 中型金矿
归零：树桩 / 碎石残骸 / 最小金矿，同时生成掉落物
残骸：完整显示 2 秒，再用 1 秒渐隐，随后销毁
```

- 两种树的大、小形态均使用现有随风摇摆动画，树桩为静态残骸。
- 普通石头使用两组大小静态图，另补两种对应碎石残骸。
- 金矿六套大小素材按 `1 → 3 → 5`、`2 → 4 → 6` 组成两种资源节点，并保留发光动画。
- 三阶段外观由通用 `Harvestable` 控制；每个阶段既可放 Animator，也可放静态 Sprite，不为树、石头、金矿分别复制逻辑。
- 资源节点允许通过 Sprite Renderer 的 Color 调色派生区域变体；代码淡出只修改 Alpha，不覆盖 RGB、Sorting Layer、Pivot 等编辑器配置。

### 直接采摘资源

- 药草两种（一大一小）、灌木两种（一大一小），未采摘时播放随风摇摆动画。
- 药草和灌木不做大小受损阶段；采摘后立即停止交互与摇摆，保留当前或指定静态外观，完整显示 2 秒，再用 1 秒渐隐并销毁。
- 直接采摘流程后续在可攻击资源验证完成后单独接入，避免一次修改两条交互链。

### 动态资源图标

- 金矿等场景掉落物可以用 Sprite Renderer 播放闪光帧。
- 背包使用 UI Image，不能直接复用针对 Sprite Renderer 制作的 Animation Clip；后续由 ItemData 保存可选动画帧，让场景掉落与背包 Image 共用同一份帧数据。
- 没有动画帧的普通物品继续使用静态 `icon`，不增加额外开销。

### 素材补充优先级

1. 中土地面、土路、树墙和营地地标；
2. 黄色普通敌人的完整动作；
3. 怪物命中、攻击与死亡 VFX；
4. 西山石地、裂缝、悬崖和余烬；
5. 南林树墙、紫雾、陷阱与发光植物；
6. 北荒雪地、风场、冰墙与残骸；
7. 东海水岸、礁石、浅水和渡船点；
8. 最后统一整理背包、HUD、按钮和图标边框。

## 11. 详细开发顺序

### 阶段 A：中土战斗与美术样板（当前阶段）

目标：把“出生点探索 → 遇怪 → 进竞技场 → 战斗 → 掉落 → 回营地”做成可展示闭环。

1. **主角近距离法术收尾**
   - 已完成星尘 VFX、鼠标 / 手机方向规则、扇形判定。
   - 实机继续微调伤害延迟、攻击间隔、VFX 位移与判定手感。
2. **第一只黄色普通怪动画管线**
   - 选动作最完整的一只黄色哥布林或黄色人类。
   - 只先接一只：Idle → Walk → Attack → Hit → Death。
   - 复用现有 `EnemyBase + EnemyData + 行为组件`，不新建整套敌人继承链。
   - 验证世界巡逻、进战斗、竞技场生成、扣血、死亡和胜利返回。
3. **扩展黄色主力怪**
   - 第一只跑通后，再复制动画管线到剩余黄色哥布林与人类。
   - 通过 `EnemyData` 和组件组合形成角色差异，避免复制整份逻辑脚本。
4. **波次组合**
   - 先做 2～3 种容易读懂的组合：数量型、远近混合、单精英带杂兵。
   - 验证背刺半血、发现倍率、死亡计数和掉落链没有被新 prefab 破坏。
5. **中土 `3×3 屏` 地图换皮**
   - 先画中央营地与一条门路作为样板，再复制到四向。
   - 接入树、矿、药草的分阶段受损表现。
   - 放置四门预告怪与区域视觉线索。
6. **中土 UI / 战斗反馈打磨**
   - 五颗心血条方案；
   - 背包物品图标与 HUD 整理；
   - 主角远程、怪物攻击、命中火花；
   - 受击红闪和轻微镜头震动后置到基础链稳定之后。

**阶段 A 完成标准：** 新玩家从营地出发，能理解移动、采集、星尘普攻、进竞技场、掉落、商店与回家；录一段 Demo 时不再明显看到占位怪和占位地面。

### 阶段 B：区域传送地基

1. 在 `MainWorld` 中规划五个彼此隔离的地图块坐标。
2. 做通用门 / 渡船交互，只负责传送、相机 Snap 和入口记录。
3. 每区配置入口、返回点、安全点和复活点。
4. 验证背包、装备、金币、箱子、商店和 GameManager 状态在远距离传送后保持正常。
5. 先只接通中土 ↔ 西山，不一次部署四区。

### 阶段 C：西山首个完整区域

1. 先用简单色块画出纵向主路、裂缝、支路、捷径和回环。
2. 单独实现并测试裂缝坠落与安全落点。
3. 再接入高机动性装备对捷径的影响。
4. 导入红色主力怪，随后接镰刀怪、牛头人等与地形强相关的敌人。
5. 制作废弃营地安全点、恶魔区、地牢入口。
6. 最后接首个正式 Boss；Boss 身份从动作完整的高级恶魔中确认。

**阶段 C 完成标准：** 不看 UI 名字，玩家仅凭路线、裂缝、敌人组合和色调就能认出西山；位移装备明显改变探索路线。

### 阶段 D：南林迷雾与女巫线

1. 先做一个两房间迷雾原型，验证遮挡、可见圈与性能。
2. 做一种有视觉提示的陷阱，先测试公平性。
3. 做发光植物 / 安全视野点，再扩展到完整 `4×4 屏`。
4. 接入史莱姆、蘑菇、紫色主力怪。
5. 在中土、西山、南林入口逐步布置女巫分身商店和对话线索。
6. 完成女巫真身契约战，并让战后商店继续合理存在。

### 阶段 E：北荒风场与血怪生态

1. 先用测试场验证稳定风向对子弹轨迹的影响。
2. 加入清晰风向视觉和避风区，再测试玩家能否靠观察修正射击。
3. 设计药水、复活道具与安全点的消耗节奏。
4. 建立横向风雪地图，加入废弃远征队与血怪巢穴。
5. 分批接入五类血怪，再加入少量蓝色外来者和人类剑士。
6. 最后决定竞技场近距离能力是否需要扩展；在此之前绝不直接禁用远程攻击。

### 阶段 F：东海群岛与外交

东海放在三大区域有基础内容后制作，因为它需要复用各区角色和世界关系。

1. 先搭港口岛与一座被入侵的小岛，验证渡船传送。
2. 放入西山镰刀怪、南林女巫等跨区角色，验证“世界交汇”是否自然。
3. 引入两位其他主角模板，确定两种立场。
4. 做第一条三选一或二选一外交任务，只影响敌对状态、商店或支援之一。
5. 再扩展到 4～5 座岛，并让先前区域选择影响东海终局。

### 阶段 G：全局收束

- 中土随区域进度发生可见变化；
- 检查四区门、复活点、死亡掉落和区域返回；
- 统一敌人血条、受击反馈、掉落和音效；
- 更新手机旋转、血条和波次遗留问题；
- 录制完整 Demo、打包 PC / Android、整理 GitHub 与简历描述。
